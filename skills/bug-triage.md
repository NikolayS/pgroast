# Basic pgsql-bugs Triage Skill (Default)

Use this rubric to prioritize incoming `pgsql-bugs` reports.

## Origin

- `production_hit`: reported from a live production server, customer workload, or real upgrade.
- `real_user_nonprod`: reported by a user in development, staging, or normal application testing.
- `synthetic_ai_hunt`: generated by a fuzzer (sqlsmith, sqlancer), static scan, or synthetic query against `master`/`devel`.
- `unclear`: not enough context to tell.

## Impact priority

1. Data loss or corruption
2. Wrong results or missing/duplicate rows
3. Crash, assertion failure, or OOM
4. Regression from an earlier supported major or minor version
5. Performance degradation
6. Minor or documentation issue
